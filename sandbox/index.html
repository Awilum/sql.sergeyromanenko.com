Песочница SQL

SQLite работает в браузере.
Две учебные базы уже загружены:
«Игроки» и «Интернет-магазин».

SQLiteБез регистрацииДанные не уходят на сервер

Важно

Песочница работает только с SQLite. Вы можете выполнять SQL-запросы прямо в браузере, экспериментировать с таблицами и изучать результаты. Синтаксис и возможности других СУБД (MySQL, PostgreSQL, SQL Server, Oracle) могут отличаться. Курсы на Stepik в основном используют MySQL — перед переносом запроса проверяйте функции в документации своей СУБД.

SQL-запрос

Запуск SQLite…

Нажмите Ctrl или Cmd с Enter, чтобы выполнить запрос из редактора.

Предустановленные базы данных

В песочнице доступны две предустановленные базы данных: Игроки и Интернет-магазин. Выберите базу, чтобы посмотреть её структуру и SQL-скрипт создания.

Таблиц пока нет. Загрузите пример датасета или напишите CREATE TABLE и выполните его.

Скрипт схемы

Скрипт, который строит и заполняет базу данных. Вставьте схему или дамп из любой базы SQLite и нажмите Построить базу. Он выполняется в этом браузере, в памяти.

Скрипт схемы создаёт базу с нуля: CREATE TABLE, INSERT, индексы. Он отделён от редактора запросов — постройте базу, а затем пишите к ней SQL сверху. Диалект — SQLite (об учебной базе курса на MySQL см. примечание выше).

Результаты

Напишите SQL и нажмите Выполнить SQL.

Скопировать:

Всё выполняется в этом браузере: база данных в памяти, ничего не загружается на сервер.

Что можно делать

  • Выполнять SELECT, JOIN, GROUP BY, CTE и оконные функции.
  • Смотреть схему и типы столбцов.
  • Создавать свою базу из скрипта схемы.
  • Сбрасывать базу, импортировать и экспортировать файл SQLite.
  • Переключаться между учебными базами данных.

Чего здесь нет

  • Серверной проверки заданий.
  • Сохранения запросов между визитами.
  • Достижений, прогресса и сертификатов — это в тренажёре.
  • MySQL-специфичных функций.

Важно помнить

Песочница использует SQLite, а курсы на Stepik в основном MySQL. Базовый SQL совпадает, но функции работы с датами, строками и типами могут отличаться. Перед переносом запроса проверьте документацию своей СУБД.
