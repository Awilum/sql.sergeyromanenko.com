    • Справочник SQL — Синтаксис SELECT, WHERE, JOIN, GROUP BY, CTE, оконные функции и другие темы
      • SELECT — Выбирает столбцы и вычисляемые выражения из таблицы.
      • WHERE — Оставляет строки, для которых условие истинно.
      • ORDER BY и LIMIT — Сортирует результат и ограничивает число строк.
      • DISTINCT — Удаляет одинаковые строки из результата.
      • GROUP BY и HAVING — Собирает строки в группы и фильтрует уже готовые группы.
      • JOIN — Соединяет строки двух таблиц по условию ON.
      • NULL — Отмечает отсутствующее или неизвестное значение.
      • CASE — Возвращает значение по первому выполненному условию.
      • IN, BETWEEN, LIKE — Три коротких способа записать список, диапазон или шаблон.
      • UNION и UNION ALL — Складывает результаты запросов один под другим.
      • Подзапросы и CTE — Разбивает запрос на именованные шаги.
      • Оконные функции — Считают по окну строк, не сворачивая результат.
      • INSERT, UPDATE, DELETE — Добавляет, изменяет и удаляет строки.
      • Диалекты SQL — Базовый синтаксис общий, функции и ограничения различаются.
