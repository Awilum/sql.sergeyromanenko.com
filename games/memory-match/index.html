СЕРТИФИКАТ ИГРОВОГО ДОСТИЖЕНИЯ

SQL Memory Match · курс «SQL Введение»

Сертификат формируется на основе результатов завершённой игровой сессии SQL Memory Match.

Сертификат создаётся непосредственно в браузере. При создании ссылки имя и результаты включаются в её содержимое в сжатом, но не зашифрованном виде. Любой, у кого есть ссылка, сможет просмотреть эти данные. Не включайте конфиденциальную информацию.

Укажите имя, которое будет отображаться в сертификате. Оно используется только для отображения и не служит ключом поиска; не сохраняется в форме или базе приложения, но при создании ссылки включается в её содержимое. Английская версия использует написание латиницей; без него используется то же имя, что и в русской.

Готовим предпросмотр…

PNG создаётся прямо в браузере из SVG-макета (A4, ~300 DPI, 3508×2480) и никуда не отправляется. Имя не сохраняется: при следующем открытии диалога его нужно указать снова. Идентификатор и дата завершения относятся к завершённой игровой сессии. Идентификатор — уникальный информационный знак экземпляра, а не код проверки подлинности.

Это информационная копия сертификата. Имя, дата и результаты могут быть изменены. Сертификат не является независимым подтверждением личности участника или факта получения достижения.

SQL Memory Match

Учебная база «Игроки» спрятана в карточках: SQL-команды слева, их объяснения справа. Ваша задача — найти все связанные пары.

Открывайте по две карточки за ход. Соберите все пары как можно быстрее — и постарайтесь потратить как можно меньше ходов.

Три уровня сложности — от базовых SELECT и WHERE до оконных функций — и два режима: «На время» и «Спокойный».

Лучшие результаты по каждому уровню сохраняются в браузере и показываются в конце игры.

Правила игры

На игровом поле расположены закрытые карточки. Каждая карточка содержит либо SQL-конструкцию (команду, функцию, оператор), либо её определение из курса «SQL Введение».

Как играть

SQL Memory Match помогает закрепить материал курса «SQL Введение» в формате игры на поиск совпадений. Выберите уровень сложности и подходящий режим игры.

Режим без ограничения времени

Изучайте SQL в своём темпе. Открывайте карточки, находите соответствующие пары, используйте подсказки и читайте небольшие объяснения из курса после каждого успешного совпадения. Здесь можно спокойно разобраться в понятиях и запомнить их без спешки.

Режим на время

Проверьте свою память и скорость. Найдите все пары как можно быстрее. В этом режиме нет подсказок и поясняющих уведомлений во время игры: сосредоточьтесь на карточках и постарайтесь улучшить свой результат.

Сложность и режимы

Сложность определяет количество пар и карточек, а режим игры выбирает, будете ли вы проходить задание с подсказками и объяснениями или на время.

  • Начальный: 6 пар, 12 карточек.
  • Средний: 8 пар, 16 карточек.
  • Продвинутый: 12 пар, 24 карточки.

Связь с курсом «SQL Введение»

Игра полностью синхронизирована с учебной программой курса«SQL Введение». Все формулировки соответствуют урокам на Stepik и главам книги «SQL Введение».

Сложность игры повышается постепенно:

  • Начальный уровень (6 пар): Таблица, SELECT, FROM, DISTINCT, SELECT *, LIMIT.
  • Средний уровень (8 пар): ORDER BY, DESC, ASC, WHERE, BETWEEN, LIKE, IN, AS.
  • Продвинутый уровень (12 пар): GROUP BY, HAVING, COUNT(*), SUM, AVG, MIN, MAX, IS NULL, OFFSET, ROUND, AND, OR.
