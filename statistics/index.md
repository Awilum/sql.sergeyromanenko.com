## Как собираются данные

1. Скрипт читает список курсов из конфигурации сайта.
2. Запрашивает публичный индекс, профиль, карточки и программы курсов в StepStat.
3. Нормализует ответы: числа, доступ, модули, навыки.
4. Проверяет структуру и полноту снимка.
5. Записывает JSON атомарно, только после успешной проверки.

Если API недоступен, отвечает ошибкой или отдаёт неполные данные, скрипт завершается с ненулевым кодом, а последний хороший снимок остаётся на месте. Сайт продолжает собираться. Повторы ограничены, таймауты заданы, ответы 429 и 5xx обрабатываются с паузой.

## Что показывается и что нет

- Доступ — бесплатный или платный; условия указаны на Stepik.
- Рейтинг курса выводится только при наличии отзывов.
- Рейтинг программы скрыт: подтверждённого количества отзывов нет.
- Число учащихся и отзывов — на момент снимка, а не в реальном времени.
- Данные обновляются по расписанию и вручную; задержка возможна.

## Проверить самостоятельно

Исходные значения можно посмотреть в публичном профиле [StepStat](https://stepstat.ru/user/561566563) и на страницах курсов Stepik.

Дата последнего обновления: 13 ноября 2026. Схема снимка: версия 1.

Поля снимка

- **Учащиеся:** learners_count
- **Отзывы:** reviews_count
- **Рейтинг:** rating
- **Уроки:** lessons_count
- **Доступ:** is_free, price, currency_code
- **Модули:** content.modules

Ограничение

StepStat — сторонний сервис. Его API не документирован как стабильный контракт. Поэтому сайт хранит снимок и не зависит от сети при сборке.
