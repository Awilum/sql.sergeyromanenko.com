# SQL для начинающих

Большой системный курс по основам SQL: синтаксис, типы данных, функции, соединения таблиц, подзапросы и изменение данных. Материал построен вокруг MySQL и практики на реальных запросах.

## Для кого

Для IT-специалистов, тестировщиков, аналитиков, маркетологов, администраторов и всех, кто работает с SQL-базами.

## Что нужно знать заранее

Базовые знания информатики и математики. Предыдущий опыт SQL не обязателен, но курс идёт от простого к сложному.

## Чему учит курс

- Писать запросы SELECT и выбирать данные из таблиц.
- Фильтровать через WHERE и HAVING, группировать через GROUP BY.
- Использовать MIN, MAX, COUNT, AVG и SUM.
- Работать со строковыми, числовыми и датовыми функциями.
- Применять CASE, COALESCE, NULLIF и IF.
- Соединять таблицы через INNER, LEFT, RIGHT, FULL, CROSS и SELF JOIN.
- Писать подзапросы и объединять запросы через UNION.
- Создавать, изменять и удалять таблицы и строки.
- Использовать представления и базовые операции с данными.
