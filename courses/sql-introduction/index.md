# SQL Введение

Бесплатный курс для первого знакомства с SQL и реляционными базами данных. Вы разберёте, как устроены таблицы, научитесь выбирать, фильтровать и сортировать данные, считать агрегаты и группировать результаты.

## Для кого

Для тех, кто никогда не работал с базами данных: студентов IT-специальностей, начинающих аналитиков, тестировщиков, backend-разработчиков и менеджеров проектов.

## Что нужно знать заранее

Опыт программирования не нужен. Достаточно базовой компьютерной грамотности и готовности разбираться в логике.

## Чему учит курс

- Понимать, как устроены реляционные базы данных и таблицы.
- Писать запросы SELECT и выбирать нужные столбцы.
- Фильтровать строки с WHERE и сортировать результаты через ORDER BY.
- Ограничивать выборку и использовать псевдонимы.
- Считать значения функциями COUNT, SUM, AVG, MIN и MAX.
- Группировать данные с помощью GROUP BY.
- Решать практические задачи на учебной базе данных.
