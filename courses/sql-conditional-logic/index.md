## Для кого

Для аналитиков, backend-разработчиков, QA, BI-аналитиков и всех, кто уже знает основы SQL и хочет писать предсказуемые условия.

## Что нужно знать заранее

Уверенное владение SELECT, WHERE, ORDER BY, GROUP BY, HAVING и агрегатными функциями.

## Чему учит курс

- Различать TRUE, FALSE и UNKNOWN и понимать трёхзначную логику.
- Правильно работать с NULL и избегать типичных ошибок.
- Комбинировать условия через AND, OR и NOT.
- Использовать BETWEEN, IN и LIKE.
- Применять CASE для преобразования и категоризации данных.
- Писать условную агрегацию.
- Использовать условия в SELECT, ORDER BY, GROUP BY, HAVING и UPDATE.
