# Проверка знаний и подготовка к собеседованию по SQL

Бесплатный курс-тест по ключевым темам SQL. Вопросы показывают, что вы понимаете, а где остались пробелы, и помогают подготовиться к собеседованию.

[Открыть курс на Stepik](https://stepik.org/a/280145/)

[Попробовать в песочнице](https://sql.sergeyromanenko.com/sandbox/)

Переход на Stepik · условия доступа указаны там

## Для кого

Для студентов IT-специальностей, junior-аналитиков, QA, backend-разработчиков и всех, кто готовится к интервью с SQL.

## Что нужно знать заранее

Знание основ SQL. Если базы нет, сначала пройдите «SQL Введение» и «SQL для начинающих».

## Чему учит курс

- Проверить знания по ключевым темам SQL.
- Найти пробелы в понимании запросов.
- Потренироваться на формате вопросов с вариантами ответов.
- Оценить готовность к техническому собеседованию.
