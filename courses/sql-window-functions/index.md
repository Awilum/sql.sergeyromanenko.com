# SQL Оконные функции

Аналитические возможности SQL: OVER и PARTITION BY, агрегаты как оконные функции, ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD и рамки окна. Для тех, кто уже уверенно пишет JOIN и GROUP BY.

## Для кого

Для аналитиков данных, backend-разработчиков, BI-аналитиков, инженеров данных и администраторов баз данных.

## Что нужно знать заранее

SELECT, WHERE, GROUP BY, HAVING и агрегатные функции. JOIN и подзапросы желательны.

## Чему учит курс

- Использовать оконные функции в запросах.
- Работать с OVER() и PARTITION BY.
- Применять агрегатные функции как оконные.
- Считать накопительные суммы и средние.
- Ранжировать строки через ROW_NUMBER, RANK и DENSE_RANK.
- Сравнивать строки через LAG и LEAD.
- Управлять рамками окна через ROWS и RANGE.
- Решать аналитические задачи на учебной базе.
