SQL Общие табличные выражения

Курс о WITH и общих табличных выражениях: как разбить сложный запрос на понятные шаги, заменить вложенные SELECT и подготовить данные к оконным функциям.

Открыть курс на StepikПопробовать в песочнице

Переход на Stepik · условия доступа указаны там

Для кого

Для аналитиков, разработчиков, QA, BI-специалистов и всех, кто хочет писать поддерживаемый SQL.

Что нужно знать заранее

Уверенные SELECT, WHERE, GROUP BY, HAVING, ORDER BY, JOIN и подзапросы.

Чему учит курс

  • Создавать CTE через WITH.
  • Использовать один и несколько CTE в запросе.
  • Заменять вложенные SELECT читаемой структурой.
  • Комбинировать CTE с JOIN, GROUP BY и HAVING.
  • Выполнять пошаговую обработку данных.
  • Использовать CTE вместе с оконными функциями.
  • Разбирать сложные запросы на именованные шаги.
