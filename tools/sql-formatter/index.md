## Зачем форматировать SQL-код

SQL-запрос может возвращать правильный результат, но при этом оставаться неудобным для чтения. Когда запросы становятся длиннее, появляются JOIN, подзапросы, группировки и сложные условия, единый стиль оформления помогает быстрее понимать структуру кода, находить ошибки и поддерживать запросы.

## Какие правила оформления применяются

1. 01 **Ключевые слова заглавными буквами.** SELECT, FROM, WHERE, JOIN и другие зарезервированные слова оформляются в едином регистре.
2. 02 **Единые отступы.** Структура запросов, JOIN и вложенных SELECT становится визуально понятной.
3. 03 **Переносы логических условий.** AND и OR располагаются на отдельных строках.
4. 04 **Пробелы и выравнивание.** Операторы, запятые и выражения оформляются последовательно, структурные ключевые слова выравниваются по правой границе.
5. 05 **Структура сложных запросов.** Подзапросы, CASE, INSERT, UPDATE и CREATE TABLE получают соответствующее оформление.
6. 06 **Комментарии сохраняются.** Текст комментариев и строковых литералов не изменяется: меняется только оформление, а не содержимое.

## На основе SQL Style Guide

В основе форматирования лежит SQL Style Guide — руководство по написанию понятного и последовательного SQL-кода, созданное Саймоном Холиуэллом (Simon Holywell). Оно описывает единые принципы именования, пробелов, отступов, ключевых слов и оформления SQL-запросов. Этот инструмент реализует его применимые к автоматическому форматированию рекомендации.

## Часто задаваемые вопросы

- **Изменяет ли форматирование смысл SQL-запроса?:** Нет. Форматирование меняет только оформление: отступы, переносы строк и выравнивание ключевых слов.
- **Какой стиль оформления используется?:** Инструмент следует SQL Style Guide Саймона Холливелла: ключевые слова, отступы и структура запроса оформляются по его рекомендациям.
- **Можно ли форматировать несколько запросов сразу?:** Да, если запросы разделены точкой с запятой; каждый будет оформлен отдельно.
- **Выполняется ли SQL в базе данных?:** Нет. Инструмент только форматирует текст SQL и не выполняет запросы.
- **Отправляются ли данные на сервер?:** Нет, форматирование выполняется локально в браузере.
