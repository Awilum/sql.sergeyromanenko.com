Форматирование SQL-кода

Приведите SQL-запрос к единому стилю оформления по SQL Style Guide: выравнивание ключевых слов, отступы, JOIN, подзапросы и переносы строк.

SQL Style GuideЛокально в браузереБез регистрации

Важно

Форматирование меняет только представление SQL-кода, а не логику запроса. Инструмент не выполняет запросы и не проверяет результат их выполнения.

Исходный SQL

Ctrl или Cmd с Shift + F — форматировать запрос из редактора.

Результат форматирования

Стиль: SQL Style Guide

Оформление меняет только вид запроса, а не его логику. Запросы никуда не отправляются и не выполняются.

Зачем форматировать SQL-код

SQL-запрос может возвращать правильный результат, но при этом оставаться неудобным для чтения. Когда запросы становятся длиннее, появляются JOIN, подзапросы, группировки и сложные условия, единый стиль оформления помогает быстрее понимать структуру кода, находить ошибки и поддерживать запросы.

Какие правила оформления применяются

  1. 01Ключевые слова заглавными буквами. SELECT, FROM, WHERE, JOIN и другие зарезервированные слова оформляются в едином регистре.
  2. 02Единые отступы. Структура запросов, JOIN и вложенных SELECT становится визуально понятной.
  3. 03Переносы логических условий. AND и OR располагаются на отдельных строках.
  4. 04Пробелы и выравнивание. Операторы, запятые и выражения оформляются последовательно, структурные ключевые слова выравниваются по правой границе.
  5. 05Структура сложных запросов. Подзапросы, CASE, INSERT, UPDATE и CREATE TABLE получают соответствующее оформление.
  6. 06Комментарии сохраняются. Текст комментариев и строковых литералов не изменяется: меняется только оформление, а не содержимое.

Как пользоваться форматтером

01 — Вставьте запрос

Скопируйте SQL-код в исходный редактор.

02 — Отформатируйте

Нажмите кнопку форматирования или сочетание клавиш Ctrl+Shift+F.

03 — Скопируйте результат

Используйте готовый SQL-код в своём проекте, учебном задании или редакторе базы данных.

На основе SQL Style Guide

В основе форматирования лежит SQL Style Guide — руководство по написанию понятного и последовательного SQL-кода, созданное Саймоном Холиуэллом (Simon Holywell). Оно описывает единые принципы именования, пробелов, отступов, ключевых слов и оформления SQL-запросов. Этот инструмент реализует его применимые к автоматическому форматированию рекомендации.
