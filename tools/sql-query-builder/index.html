SQL-конструктор запросов

Создавайте SQL-запросы визуально, без необходимости запоминать синтаксис. Выбирайте таблицы и столбцы, добавляйте соединения, условия, группировку, сортировку и агрегатные функции. Получайте готовый SQL-код для SQLite и MySQL, копируйте запросы и используйте их в своих проектах.

SQLite MySQL Работает в браузере Без регистрации

Важно

SQL-конструктор запросов помогает создавать запросы, но не подключается к вашей базе данных и не выполняет SQL-команды. Вы настраиваете запрос визуально, а инструмент формирует готовый SQL-код. Все введённые значения и настройки обрабатываются локально в браузере.

Шаг 1 из 3

Выберите базу данных

От СУБД зависят кавычки для имён, доступные функции и поддерживаемые конструкции SQL. Выбор можно изменить на следующем шаге или вернуться к нему позже.

Сначала выберите SQLite или MySQL.

Сбросить запрос?

Текущие параметры будут очищены.

Текущие параметры запроса будут очищены. Выбранная СУБД и тип запроса сохранятся.

Какие SQL-запросы можно создавать

Один конструктор объединяет инструменты для создания запросов разных типов и работы с основными конструкциями SQL.

1. Выборка данных

Создавайте SELECT-запросы, выбирайте столбцы, добавляйте DISTINCT, фильтруйте записи и ограничивайте количество результатов.

2. Соединение таблиц

Объединяйте данные из нескольких таблиц с помощью INNER JOIN, LEFT JOIN, RIGHT JOIN и других поддерживаемых типов соединений.

3. Фильтрация данных

Настраивайте WHERE, IN, NOT IN, BETWEEN, LIKE и комбинируйте несколько условий с помощью AND и OR.

4. Группировка и аналитика

Используйте GROUP BY, HAVING, COUNT, SUM, AVG, MIN и MAX для построения аналитических запросов.

5. Условные и строковые выражения

Создавайте CASE WHEN, COALESCE, SUBSTRING, LEFT, RIGHT и REPLACE без ручного написания выражений.

6. Изменение данных

Формируйте INSERT, UPDATE и DELETE, добавляйте несколько значений и условий и контролируйте область изменения записей.

Как пользоваться SQL-конструктором

  1. Выберите СУБД.

    Укажите, для какой базы данных нужен запрос: SQLite или MySQL.

  2. Определите тип запроса.

    Выберите SELECT, INSERT, UPDATE или DELETE либо загрузите готовый пример.

  3. Настройте параметры.

    Добавьте таблицы, столбцы, соединения, условия, сортировку и необходимые SQL-выражения.

  4. Получите готовый SQL.

    Проверьте автоматически сформированный запрос, скопируйте его или скачайте в файл.

Поддержка SQLite и MySQL

Конструктор учитывает различия между SQLite и MySQL при формировании SQL-кода. Для каждой СУБД используются собственные правила экранирования идентификаторов, представления значений, функций и отдельных конструкций SQL. Если выбранная возможность недоступна в конкретной СУБД, инструмент сообщит об этом вместо генерации некорректного запроса.

Ваши данные остаются в браузере

Для создания запросов не требуется подключение к базе данных или регистрация. Конструктор формирует SQL непосредственно на вашем устройстве. Таблицы, названия столбцов, введённые значения и параметры запросов не отправляются на сервер.

Часто задаваемые вопросы

Какие базы данных поддерживает SQL-конструктор запросов?
Доступны SQLite и MySQL. При создании запроса конструктор учитывает особенности выбранной СУБД и формирует соответствующий SQL-код.
Нужно ли подключать собственную базу данных?
Нет. Для создания запроса достаточно указать названия таблиц и столбцов вручную.
Можно ли создавать JOIN между несколькими таблицами?
Да. Можно добавлять несколько соединений, выбирать тип JOIN, указывать таблицы, псевдонимы и условия ON или USING.
Можно ли создавать сложные условия WHERE?
Да. Конструктор поддерживает сравнения, IN, NOT IN, BETWEEN, LIKE, IS NULL и другие основные операторы. Несколько условий можно объединять с помощью AND и OR, в том числе в группах со скобками.
Можно ли создавать запросы GROUP BY и HAVING?
Да. Вы можете группировать записи, использовать COUNT, SUM, AVG, MIN и MAX и фильтровать сгруппированные результаты с помощью HAVING.
Выполняет ли инструмент SQL-запросы?
Нет. SQL-конструктор запросов только формирует SQL-код. Готовый запрос можно скопировать и выполнить в собственной среде работы с базой данных.
Отличается ли SQL для SQLite и MySQL?
Да. У этих СУБД есть различия в синтаксисе, функциях и поддерживаемых конструкциях. Поэтому перед созданием запроса необходимо выбрать соответствующую СУБД.
Отправляются ли мои данные на сервер?
Нет. Создание SQL-запросов происходит локально в браузере. Инструмент не требует передачи данных на сервер.
