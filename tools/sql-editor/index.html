SQL Редактор

Пишите и выполняйте SQL-запросы, создавайте собственные базы SQLite или импортируйте готовые файлы. Просматривайте структуру таблиц и экспортируйте результаты в удобных форматах.

SQLiteЛокально в браузереБез регистрации

Важно

Редактор работает только с SQLite. Запросы, база и результаты остаются в вашем браузере: ничего не загружается на сервер. Синтаксис других СУБД (MySQL, PostgreSQL, SQL Server) может отличаться. Курсы на Stepik в основном используют MySQL — перед переносом запроса проверяйте функции в документации своей СУБД.

Как это устроено

  • База данных в памяти вкладки. SQLite работает прямо в браузере с помощью WebAssembly. Запросы, база данных и результаты не отправляются на сервер.
  • Пустая база по умолчанию. Создайте собственные таблицы через SQL, соберите базу из инициализационного скрипта или импортируйте готовый файл SQLite.
  • Безопасная замена базы. Импорт и построение новой базы выполняются отдельно. Активная база заменяется только после успешного завершения операции.
  • Точное представление данных. INTEGER читается как точное bigint — значения больше 2⁵³−1 не теряют знаков ни на экране, ни в файле. NULL отображается как NULL, BLOB — как Base64.

Чего здесь нет

Редактор работает исключительно с SQLite. Синтаксис MySQL и PostgreSQL не поддерживается. Запросы и база существуют в памяти браузера в рамках текущей сессии; чтобы продолжить работу позже, скачайте файл базы данных.

Схема за один взгляд

Вкладка «Схема базы» показывает таблицы, представления и индексы: типы столбцов, первичные ключи, внешние ключи, UNIQUE и NOT NULL — из системных таблиц SQLite, а не из текста ваших CREATE TABLE. Нажатие на столбец вставляет его имя в запрос.
